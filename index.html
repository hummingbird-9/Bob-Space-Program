PAYLOAD FAIRING BUILDER

Build a shell from a fairing base. Add radius/height joints from bottom to top; click the top centerline to close it. Right-click removes the last joint. Green is valid, orange flags sizing, and blue flags payload clipping. Mass and cost update as you edit.

CUSTOM PART WORKSHOP

Create a part using validated JSON data. This uses a small configuration format, not arbitrary JavaScript. Engine thrust cannot exceed the strongest stock engine: 9,000 kN.

Parts are stored locally in this browser session and may be exported with your craft.
AGENCY FLAG EDITOR

LOCAL MULTIPLAYER / SERVER

Host a shared agency or compete with a friend on the same local network. The optional server relays room, agency and mission status. Both players should open the host computer's BSP address.

Offline. For LAN mode, start the included server on one computer and connect both browsers to its local address.
SERVER PACKAGES

Source and build scripts are included for Windows .exe, Linux .deb, Arch .pkg.tar.zst, and macOS .dmg. Each format must be built on its target OS.

CAMPAIGN BRIEFING

THE GREAT SURVEY RACE

Choose a destination, launch a probe or crewed craft, and plant a survey beacon before the rival agency. Agencies are randomized from the BSP universe of fictional and real-world space programs.

Competition: collect science, establish relay coverage, and claim surface survey sites. Base contests are peaceful signal-and-beacon challenges; there are no realistic weapons or missile systems.

Rival target: Duna. First successful surface survey wins.
